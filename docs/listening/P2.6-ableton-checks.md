# Manual host checks owed at the P2.6 gate

Two manual checks have been deferred twice, each time for the same reason: they need a host note to
be able to land on more than one string, and until Task P2.6 `NoteAllocator::allocate()` assigned
every note to string 0.

- The **6-note chord check** was deferred at Task P2.1, when the shipped string count moved from 1
  to 6 (ledger: "the brief's manual Ableton 6-note-chord check needs NoteAllocator multi-string
  assignment, which is P2.6").
- The **default-count 1 → 6 smoke rider** was folded in with it by the same controller ruling.
- Task P2.4 added a third reason: the bridge is now loaded and coupled, so a chord is the only
  gesture that exercises what six strings on one bridge actually sound like, and it moved its own
  sympathetic-shimmer check here for the same reason.

Nothing in this file can be run by CI or by an implementer without a DAW. It is written to be
executed in one sitting by the author, in order, with a verdict written next to each item.

---

## Setup (once)

1. Build Release and install the VST3:

   ```
   cmake --build build --config Release
   ```

   The artefact is
   `build\plugin\cnpg_plugin_artefacts\Release\VST3\cecinestpasunguitar.vst3`
   (see `docs/decisions/0001-pluginval-gate.md` for why it is not under `build\bin\`). Copy it to
   the system VST3 folder — this needs elevation, exactly as at Task P0.8.

2. Ableton Live 12 Suite (12.4.3 is the recorded reference host), 48 kHz, 128-sample buffer, one
   MIDI track with the plugin on it, generic parameter editor.

3. **Reset every parameter to its default before starting.** Every expectation below is written
   against defaults: `Strings` = 6, `Allocation Mode` = Guitar Fingering, the eight
   `String N Open Note` parameters = 40/45/50/55/59/64/35/30, `Bridge Coupling` = 0.35,
   `Retrigger Mode` = Physical, `Damper Depth` = 1.0, `Damper Felt Time` = 40 ms.

4. Record what you hear on, and on what. A verdict on unnamed monitoring is not reproducible.

## Check A — the 6-note chord (deferred from P2.1, blocked until P2.6)

**Play:** a strummed open E-major chord, low to high, one strum every two seconds, letting each
ring. In MIDI notes: 40, 47, 52, 56, 59, 64. Strum it as a strum (a few milliseconds between
notes), not as a block.

**Expect:**

| # | What to check | Pass looks like | Fail looks like |
|---|---|---|---|
| A1 | **Six voices, not one** | Six pitches sounding at once, each with its own decay. | One pitch; or six attacks that each cut the previous one off. This is the exact failure the check was deferred for — before P2.6 it was guaranteed. |
| A2 | **Fingering is plausible** | The chord sounds like a guitar chord: the low E rings longest, the top E shortest. Headless evidence: the allocator puts an open C major on x32010, the shape a player uses (`cnpg_tests "CONTRACT: GuitarFingering spreads*"`). | Notes arriving on implausible strings — e.g. every note on the low E, which would sound like one string being repeatedly re-fretted. |
| A3 | **The chord is stable** | No runaway level, no pumping from the limiter, no growth as it rings. | Level climbing after the strum, or the limiter audibly working. |
| A4 | **Sympathetic shimmer** (P2.4 item 14, moved here) | Hold the low E alone, then play staccato notes above it. The held string should shimmer sympathetically. Turn `Bridge Coupling` from 0.35 down to 0.05 and back: less shimmer, longer sustain at the low end; more shimmer, shorter. | No audible change from the coupling control at all (which would mean the bridge is not in the loop), or shimmer so strong it reads as an effect rather than as an instrument. |
| A5 | **A 7th note steals audibly and plausibly** | With all six ringing, play a 7th note. One of the ringing notes is displaced — the one struck longest ago — and the new note takes its place. There is no click at the moment it happens. | A click, a doubled note, a note that never stops, or a 7th note that produces silence. |

**Reference numbers this check exists to confirm by ear** (all are already gated headless):
six dampers releasing on one sample read −1.07 dB of click excess against a 3 dB criterion; the
steal displaces the least-recently-triggered candidate.

## Check B — default string count, 1 → 6 (the P2.1 smoke rider)

**Play:** the same open E-major chord, held.

**Do:** with the chord ringing, move `Strings` from 6 down to 1, then back up to 6. Then stop, set
`Strings` to 1, play the chord again, and set it back to 6 and play again.

**Expect:**

| # | What to check | Pass looks like | Fail looks like |
|---|---|---|---|
| B1 | **The reduction is a mute, not a cut** | Strings 2–6 fade out over about 10 ms. No click at the boundary. | A click, or the strings vanishing instantly. |
| B2 | **Coming back up is clean** | Raising the count back to 6 while the low E still rings produces no click and no jump in the low E's tone. | A click, or an audible timbral step on the string that never went away. |
| B3 | **At `Strings` = 1 the chord is monophonic** | Each note of the strum takes the string from the previous one — you hear one voice being repeatedly re-struck, which under Physical mode should sound like re-fretting rather than like six separate notes. | Six voices at `Strings` = 1 (which would mean the count is not reaching the allocator), or silence. |
| B4 | **Decay changes with the count** (P2.4 item 16) | With fewer strings switched on, the strings that remain decay differently — an idle or disabled string is a perfect absorber at its bridge port, so the bridge's damping depends on how many are live. Is that difference musical or is it a surprise? | No difference at all (the coupling is not doing what P2.4 measured), or a difference so large that changing the count sounds like changing the instrument. |

## Check C — the sustain pedal (new at P2.6)

**Play:** the open E chord. Hold the sustain pedal (CC64) down BEFORE releasing the keys, release
all six keys, then release the pedal.

**Expect:**

| # | What to check | Pass looks like | Fail looks like |
|---|---|---|---|
| C1 | **The pedal holds** | All six strings ring past their note-offs, at the undamped decay rate. | Notes damping on key release (the pedal is not reaching the allocator), or notes that never damp at all. |
| C2 | **The pedal releases together** | On pedal-up, all six damp at once, with the felt time. Nothing clicks. Headless evidence: six dampers on one sample, −1.07 dB of click excess against a 3 dB criterion. | A click; a staggered release; one string left ringing. |
| C3 | **Re-striking under the pedal cancels its release** | With the pedal down, release a key and then press it again before lifting the pedal. When the pedal comes up, that note must NOT damp — it is still held. | The re-struck note damping on pedal-up, which is a note cut off while the player is holding it. |
| C4 | **Half-pedalling does nothing surprising** | CC64 is a switch at 64: below is up, at or above is down. Sweeping the pedal slowly should produce exactly one transition each way, not a stutter. | Repeated damping/undamping as the controller wobbles around the threshold. |

## Check D — retrigger modes (checklist items 3 and 4, first judgeable here)

**Play:** on one string's range (say MIDI 45–52 with `Strings` = 1 so the allocator is forced),
(i) the same note repeatedly, and (ii) a legato line of different notes.

**Do:** toggle `Retrigger Mode` between Physical and Synth.

**Expect:**

| # | What to check | Pass looks like | Fail looks like |
|---|---|---|---|
| D1 | **Physical, same pitch** (checklist 3) | A repluck sounds like picking an already-sounding string: the sound never restarts and never gaps. No pop. Headless evidence: click excess −0.00003 dB, string RMS never below −42.4 dBFS between attacks against a −60 floor. | A gap, a restart, or a click. |
| D2 | **Physical, pitch change** (checklist 3) | The old note continues into the new one. Headless evidence: f0 lands exactly on the new pitch in 30.0 ms, click excess 0.90 dB against a 3 dB criterion. **THE OPEN QUESTION: does 30 ms of glide read as a hammer-on, or as a slide?** The glide length is `StringNetwork::setRetuneRampSeconds` and is not on the APVTS surface — if the answer is "slide", it should be, and it should be shorter. Shorter costs click margin only down to about 18 ms: 16 ms reads 6.0 dB and 8 ms reads 10.1 dB against the 3 dB criterion, but 22 ms reads 1.18 dB and passes while 28 ms reads 3.59 dB and fails, so the statistic does not order ramp lengths and there is a usable range rather than a floor at 30. (Figures re-measured at fixes wave 3 with the re-strike level-placed instead of struck at a block boundary; the shape is unchanged.) **Your ear decides this number; the gate only refuses a ramp short enough to be a step.** | An audible portamento on every fretted note (too long), or a click/chirp (too short). |
| D3 | **Synth, pitch change** (checklist 4) | An instant clean restart at the new pitch. No click, and no trace of the old pitch. Headless evidence: worst surviving old-pitch partial −93.8 dBc against a −60 dBc criterion. | A click; audible remains of the previous note; or an audible 2 ms hole before the attack (that hole is real — a Synth retrigger is delayed by 97 samples at 48 kHz — and whether it is perceptible is exactly what this item asks). |
| D4 | **The two modes are clearly different** | Physical is connected; Synth is separate. A listener should be able to tell which is selected without being told. | The toggle making no audible difference. |
| D5 | **A re-strike just after a note-off** (checklist 21) | Release a key and press it again 5–20 ms later, repeatedly, in both modes. A released note is over, so this is a FRESH note in either mode — the string is cleared and re-plucked, and the two modes should be indistinguishable here (headless evidence: the two renders are bit-identical). Pass is: it sounds like picking a string that had just been muted. **Headless evidence says the clear IS a discontinuity at these gaps** — 19.7 dB of click excess at 5.5 ms, 21.5 dB at 12.4 ms, 16.6 dB at 21.3 ms against a 3 dB criterion, falling to 0.3 dB by 52.7 ms — and cannot say whether the fresh attack landing on the same sample masks it. **Your ear decides this one.** | An audible tick or spit at the re-strike that is absent when the same note is played on a string that was already silent. Also a fail: the two modes sounding different here, which would mean the predicate is not mode-independent after all. |
